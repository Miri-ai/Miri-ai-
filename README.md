## Proyecto destacado

**[Análisis de Ventas, Clientes y Marketing con Python](https://github.com/Miri-ai/analisis-ventas-marketing-python)**

Análisis exploratorio y estadístico de datos de ventas retail: limpieza y transformación de datos, estadística descriptiva, detección de outliers, correlación entre variables y visualización con Matplotlib, Seaborn y Plotly. Incluye recomendaciones estratégicas basadas en los hallazgos.

Hallazgo destacado: 4 productos "outlier" concentran el 19.7% de los ingresos totales — un ejemplo de cómo el análisis de datos puede señalar dónde enfocar esfuerzos comerciales.
